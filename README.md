# ADHD Momentum Planner

A responsive digital planner optimized for mobile devices and tablets, designed to support productivity and wellbeing for people with ADHD.

## Features

- Daily routine tracker with top priorities and energy anchors
- Focus and mindfulness tools (breathing timer, grounding prompts, focus boosters)
- Task management with categories and priority levels
- Time-blocking template for planning focused work and breaks
- Reflection and journaling sections for daily review and growth
- Customization options for theme, typography, and spacing
- LocalStorage persistence for day-to-day use in the browser

## Run locally

```bash
python3 -m http.server 4173
```

Open: `http://localhost:4173`
